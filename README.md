# 오토 스튜디오

기획부터 업로드까지 AI 팀이 영상을 만들고, 사람은 **기획**과 **업로드** 두 곳에서만 결재하는 자동 영상 제작 스튜디오입니다.
유튜브 롱폼 · 쇼츠 · 인스타그램 릴스를 만듭니다.

```
리서치 → 기획안 → [기획 결재] → 대본 → 스토리보드 → 성우 → 이미지·영상 / 모션그래픽·자막 / 음악 / 썸네일·제목
        → 편집·마스터링 → 품질 검수(미달이면 자동 재작업) → [업로드 결재] → 업로드 → 성과 분석·학습
```

## 시작하기

필요한 것: **Node.js 20 이상**, **ffmpeg**, **Chrome**(또는 Edge).

```bash
npm install
```

```bash
npm run check
```

```bash
npm start
```

브라우저에서 `http://localhost:4400` 을 열면 관제실이 나옵니다.

API 키가 하나도 없어도 바로 돌아갑니다(**시뮬레이션**). 이때는 기획·대본이 템플릿이고 영상·음성은 자리만 채운 대체물이라, 전체 흐름과 화면을 확인하는 용도입니다. 키를 넣는 순간 그 분야부터 실제 AI로 바뀝니다.

## AI 연결하기

관제실의 **설정 → AI 연결 키**에 붙여 넣거나, `.env.example` 을 `.env` 로 복사해 채웁니다.

| 순서 | 키 | 맡는 일 |
|---|---|---|
| 1 | `ANTHROPIC_API_KEY` | 두뇌 — 리서치(웹 검색), 기획, 대본, 스토리보드, 품질 검수(영상 프레임 판독), 학습 |
| 2 | `ELEVENLABS_API_KEY` | 성우(자막 싱크용 타임스탬프 포함), 배경음악 |
| 3 | `FAL_KEY` | 이미지·영상 생성 — 키 하나로 여러 최상위 모델 사용 |
| 선택 | `OPENAI_API_KEY` | 이미지·음성 예비 |
| 선택 | `YOUTUBE_API_KEY` | 리서치 때 조회수 10만 이상 벤치마크 영상 조회 |

어떤 모델을 어떤 순서로 쓸지는 [`studio/routing.yaml`](studio/routing.yaml) 한 파일에 있습니다. 분야마다 위에서부터 시도하고, 키가 없거나 실패하면 다음 후보로 넘어갑니다. 새 모델이 나오면 맨 위에 한 줄 추가하면 됩니다. **AI 팀** 화면에서 지금 무엇이 연결돼 있는지 볼 수 있고, ‘AI 기술 스카우트’가 최신 모델을 조사해 후보를 제안합니다.

Claude 요청에는 서버 측 폴백(`fallbacks: "default"`)이 켜져 있어, 안전 분류기가 요청을 거절하면 같은 호출 안에서 다른 모델로 다시 시도합니다.

## 바로바로 바꾸기

스튜디오의 동작은 전부 [`studio/`](studio) 폴더의 파일입니다. **저장하면 재시작 없이 다음 작업부터 적용**됩니다. 화면(설정 · 라이브러리 · AI 팀)에서 고쳐도 되고 파일을 직접 고쳐도 됩니다. 형식이 틀린 파일은 저장되지 않거나, 이전 내용으로 계속 동작합니다.

| 바꾸고 싶은 것 | 파일 |
|---|---|
| 각 AI의 역할·지시문·사용 모델 | `studio/agents/*.md` |
| 그림체 (프롬프트·색·글꼴·자막·음악·목소리) | `studio/styles/*.yaml` — 파일을 추가하면 새 그림체 |
| 포맷 (화면 비율·길이·컷 길이·자막·안전 영역) | `studio/formats/*.yaml` |
| 채널 (주제·시청자·말투·오토파일럿) | `studio/channels/*.yaml` — 파일을 추가하면 새 채널 |
| 분야별 AI 모델과 우선순위 | `studio/routing.yaml` |
| 단계 순서·담당·결재 지점 | `studio/pipeline.yaml` |
| 품질 기준표 (10만 조회 기준) | `studio/rubric.yaml` |
| 합격선·예산 상한·동시 작업 수·업로드 on/off | `studio/studio.yaml` |

## 스스로 배우는 방식

팀의 기억은 **학습 노트**입니다. 매 작업마다 담당 AI의 지시문에 관련 노트가 들어갑니다.

- **결재 피드백** — 수정 요청·반려 때 적은 말에서 취향과 기준을 배웁니다. 가장 강한 신호입니다.
- **품질 검수** — QA가 돌려보낸 지적을 담당자별 교훈으로 남깁니다.
- **실제 성과** — 업로드 1·3·7일 뒤 조회수·시청 지속률을 가져와 기획 때의 예측과 비교합니다.
- **직접 지시** — 학습 화면에서 한 줄 적으면 최우선으로 매번 전달됩니다.

노트는 **학습** 화면에서 끄거나 지울 수 있습니다. 시뮬레이션에서 생긴 노트는 실제 제작에 쓰이지 않습니다.

## 실제 업로드 켜기

기본값은 **꺼짐**입니다. 꺼져 있으면 업로드 결재를 승인해도 영상·썸네일·게시 정보를 묶어 `data/outbox/` 에만 저장합니다.

1. **YouTube** — Google Cloud에서 YouTube Data API v3 와 YouTube Analytics API 를 켜고 OAuth 클라이언트(웹 애플리케이션)를 만듭니다. 승인된 리디렉션 URI에 `http://localhost:4400/api/oauth/youtube/callback` 을 넣고, 설정 화면에 클라이언트 ID·보안 비밀을 입력한 뒤 **YouTube 계정 연결**을 누릅니다.
2. **Instagram** — 비즈니스/크리에이터 계정의 액세스 토큰과 계정 ID를 입력합니다. Facebook 로그인 토큰이면 파일을 직접 올립니다. Instagram 로그인 토큰은 공개 주소에서 영상을 가져가는 방식이라 `INSTAGRAM_LOGIN_TYPE=instagram` 과 `PUBLIC_BASE_URL` 이 추가로 필요합니다.
3. 설정 화면에서 **실제 업로드**를 켭니다.

## 안전장치

- 결재 없이는 아무것도 올라가지 않습니다.
- 대체 엔진으로 만든 구간이 있는 영상은 실제 업로드가 막힙니다.
- 영상 1편당 추정 비용이 상한(`studio.yaml`의 `budget`)을 넘으면 멈추고 알려줍니다. 단가는 `routing.yaml`의 `pricing` 추정치이므로 실제 청구액은 각 제공사에서 확인하세요.
- 연결된 AI가 실패하면 조용히 대체물로 바꾸지 않고 그 단계를 실패로 표시합니다.
- 기본적으로 이 컴퓨터에서만 접속됩니다. 다른 기기에서 접속하게 하려면 비밀번호가 필수입니다.

```bash
STUDIO_TOKEN=원하는비밀번호 HOST=0.0.0.0 npm start
```

## 점검용 명령

스튜디오를 켠 상태에서 영상 한 편을 끝까지 만들어 보는 스모크 테스트입니다(결재도 스스로 승인). 키가 없으면 비용 없이 대체 엔진으로 돕니다.

```bash
npm run demo -- --format=shorts --revise-plan --revise-upload
```

## 폴더

```
studio/   설정 — AI 팀, 그림체, 포맷, 채널, 라우팅, 파이프라인, 기준표 (저장 즉시 반영)
server/   오케스트레이터, AI 어댑터, 모션그래픽 렌더러, 편집 엔진, 학습 루프
web/      관제실 화면 (빌드 과정 없음 — 파일을 고치고 새로고침하면 반영)
data/     만들어진 영상·프로젝트 기록·학습 노트·저장한 키 (git에 올라가지 않음)
```

## 지금 상태와 한계

- **검증된 것**: 시뮬레이션으로 쇼츠·릴스·롱폼 전 과정(기획 수정 요청, QA 자동 재작업, 업로드 수정 요청, 예산 정지, 오토파일럿, 설정 즉시 반영)이 끝까지 돕니다. 모션그래픽·자막 렌더링과 편집·마스터링은 실제 엔진입니다.
- **검증되지 않은 것**: 실제 API 키로 호출해 보지 못했습니다. 모델 ID와 요청 형식은 2026-11-12 기준 각 제공사 공식 문서로 확인했고, 잘못된 키로 호출해 요청이 서버까지 도달하는 것만 확인했습니다. 첫 실제 실행 때 **AI 팀** 화면의 실패 표시를 확인하세요.
- ElevenLabs `eleven_v4` 가 타임스탬프 포함 호출을 지원하는지는 문서로 확인하지 못했습니다. 실패하면 `eleven_multilingual_v2` 로 자동 전환됩니다.
- YouTube Analytics API는 노출수·클릭률(CTR)을 제공하지 않아, 학습은 조회수와 시청 지속률을 기준으로 합니다.
- 품질 기준표는 조회수 10만 이상 영상의 공통 요소를 점수화한 것이며 조회수를 보장하지는 않습니다.
- 유튜브는 대량 생산된 반복적 콘텐츠의 수익 창출을 제한합니다. 채널 주제·그림체를 다양하게 쓰고 결재 단계에서 직접 걸러 주세요.
